# Shell Assignment – EC2 Monitoring Script

## What I Did
- Launched an Ubuntu EC2 instance in AWS and connected to it using SSH.
- Installed Git in the EC2 instance.
- Created a Git repository named `shell-assignment`.
- Wrote a shell script `monitor.sh` to display:
  - running services
  - CPU usage
  - memory usage
  - disk usage
- Tested the script to ensure it runs without errors.
- Logged the script output into `monitor_logs.txt`.
- Scheduled the script to run daily using `crontab`.
- Created a GitHub repository and pushed the project files to it.
